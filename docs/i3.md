# i3 Window Manager Backend Guide

AntiAFK-RBX-Sober features specialized integration for the [i3 window manager](https://i3wm.org) using the native i3 IPC protocol (`i3-msg`), `xdotool`, and `/dev/uinput`.

---

## Requirements

| Tool                        | Purpose                     | Package                             |
| :-------------------------- | :-------------------------- | :---------------------------------- |
| `i3-msg`                    | i3 IPC interface            | Part of i3 session                  |
| `xdotool`                   | Pointer coordinates & input | `xdotool`                           |
| `maim` / `import` / `scrot` | Auto Reconnect screenshot   | `maim` or `imagemagick`             |
| `/dev/uinput`               | Virtual input emulation     | Built-in kernel module (optional\*) |

> **Zero-Permission Mode (\*)**:
> If `/dev/uinput` permissions are not granted, AntiAFK automatically falls back to `xdotool` (XTest), providing complete input emulation without requiring root or udev configuration.

---

## Architecture & How It Works

### 1. i3 Layout Tree Navigation via IPC

AntiAFK connects directly to the active i3 socket (`$I3SOCK`) and retrieves the layout tree via JSON IPC:

```bash
i3-msg -t get_tree
```

- Recursively parses containers and floating nodes to locate Sober windows by `window_properties.class` or `window_properties.title`.
- Focuses the target window via:
    ```bash
    i3-msg [id="<id>"] focus
    ```
- **Multi-Instance**: Iterates over all matching Sober window containers across workspaces sequentially.

### 2. Cursor Preservation & Focus Restoration

- Captures global pointer coordinates via `xdotool getmouselocation --shell` before focusing Sober.
- Restores coordinates using `xdotool mousemove --sync <x> <y>` after actions finish.
- Remembers previously focused window container and restores focus to your active window.

### 3. User Safe ("Don't Interrupt Me")

Dual-layer activity detection:

1. Low-level physical `evdev` listening on `/dev/input/event*` for any keyboard or mouse input.
2. Pointer delta sampling via `xdotool getmouselocation` over a 3-second window. Any movement pauses automation for 3 seconds.

### 4. Hide Game (i3 Scratchpad)

In tiling window managers, traditional window minimization does not exist. AntiAFK integrates with i3's scratchpad:

- **Hiding**: moves the Sober window to the scratchpad:
    ```bash
    i3-msg [id="<id>"] move scratchpad
    ```
- **Unhiding**: restores the window when automation stops or unhide is triggered:
    ```bash
    i3-msg [id="<id>"] scratchpad show
    ```

### 5. Auto Reconnect

- Captures target window via `maim -i <id>`, ImageMagick `import -window <id>`, or `scrot -u`.
- Analyzes pixels for Roblox's disconnected modal (`RGB(57, 59, 61)`).
- Warps cursor to the Reconnect button and clicks via `xdotool` or `/dev/uinput`.

### 6. FPS Capper (CPU Throttling)

- Throttles Sober via systemd user cgroup scopes or `SIGSTOP`/`SIGCONT` duty cycle.
- **Unlock on Focus**: Checks the focused container directly from i3's IPC tree (`focused: true`), temporarily releasing the CPU quota whenever you switch focus to Sober.

## Diagnostics in the App

Under the **Diagnostics** tab in AntiAFK:

- **Desktop Session**: reports `i3 (X11)`.
- **xdotool Utility**: verifies `xdotool --version`.
- **i3-msg Utility**: verifies `i3-msg -v`.
- **Screen Capture**: reports detected screenshot utility (`maim`, `import`, or `scrot`).
- **Input Emulation**: shows `Ready` (`/dev/uinput`) or `xdotool fallback active`.

## Troubleshooting

- **"An i3 session (I3SOCK) is required"**:
  Ensure the application is launched inside an active i3 session where `$I3SOCK` is set.
- **"xdotool Utility: Error"**:
  Install `xdotool` via your package manager (`sudo pacman -S xdotool` / `sudo apt install xdotool`).
- **Forced Backend Selection**:
    ```bash
    AntiAFK-RBX-Sober --force-desktop i3
    ```
