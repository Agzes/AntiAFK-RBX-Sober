# X11 Backend Guide

AntiAFK-RBX-Sober supports all standard X11 window managers (XFCE, Cinnamon, etc.) via X11 automation tools, `xdotool`, and `/dev/uinput`.

---

## Requirements

| Tool                        | Purpose                                          | Package                             |
| :-------------------------- | :----------------------------------------------- | :---------------------------------- |
| `xdotool`                   | Window activation, pointer query, fallback input | `xdotool`                           |
| `wmctrl`                    | Window enumeration (recommended)                 | `wmctrl` (optional)                 |
| `maim` / `import` / `scrot` | Window screenshot for Auto Reconnect             | `maim` or `imagemagick`             |
| `/dev/uinput`               | Kernel-level input device                        | Built-in kernel module (optional\*) |

> **Zero-Permission Mode (\*)**:
> Unlike Wayland compositors which strictly isolate input, X11 allows input injection via XTest (`xdotool`). If `/dev/uinput` permissions are not granted, AntiAFK automatically and seamlessly falls back to `xdotool`, allowing full functionality without root or udev configuration!

## Architecture & How It Works

### 1. Window Discovery & Focus

- Queries open windows using `wmctrl -lx` (with automatic fallback to `xdotool search --class sober`).
- Identifies Sober by matching `WM_CLASS` (`sober`, `org.vinegarhq.Sober`) and window name.
- Activates windows via:
    ```bash
    xdotool windowactivate --sync <id>
    ```
- **Multi-Instance**: Cycles through all matching Sober window IDs sequentially.

### 2. Cursor Preservation & Focus Restoration

- **Cursor Tracking**: Queries global pointer position via `xdotool getmouselocation --shell` before focusing Sober, and restores coordinates with `xdotool mousemove --sync <x> <y>` after actions complete.
- **Previous Window Restoration**: Records the active window ID before automation triggered, returning focus to your previous window when done.

### 3. User Safety ("Don't Interrupt Me")

Dual-layer activity detection:

1. Physical `evdev` listening on `/dev/input/event*` for any keyboard or mouse input.
2. Pointer delta sampling via `xdotool getmouselocation` over a 3-second window. Any movement greater than 2 pixels pauses automation for 3 seconds.

### 4. Hide Game (Stealth Mode)

- Minimizes Sober windows via `xdotool windowminimize <id>`.
- Restores windows upon unhiding or stopping via `xdotool windowmap <id>` or window activation.

### 5. Auto Reconnect

- Captures the target window using `maim -i <id>`, ImageMagick `import -window <id>`, or `scrot -u`.
- Analyzes pixels for Roblox's disconnected modal (`RGB(57, 59, 61)`).
- Warps cursor to the Reconnect button and clicks via `xdotool` or `/dev/uinput`.

### 6. FPS Capper (CPU Throttling)

- Throttles Sober via systemd user cgroup scopes (`CPUQuota=X%`) or process duty-cycle fallback (`SIGSTOP`/`SIGCONT`).
- **Unlock on Focus**: Checks active window ID, parses `WM_CLASS` via `xprop -id <id> WM_CLASS`, and temporarily clears the throttle while you are playing in Sober.

## Diagnostics in the App

Under the **Diagnostics** tab in AntiAFK:

- **Desktop Session**: reports `X11 (Generic)`.
- **Input Emulation**: shows `Ready` (`/dev/uinput`) or `xdotool fallback active`.
- **xdotool Utility**: verifies `xdotool --version`.
- **wmctrl Utility**: reports `Installed` or `Optional (xdotool fallback)`.
- **Screen Capture**: reports detected capture tool (`maim`, `import`, or `scrot`).

---

## Troubleshooting

- **"xdotool Utility: Error"**:
  Install `xdotool` via your package manager (`sudo pacman -S xdotool` / `sudo apt install xdotool`).
- **"Auto Reconnect requires maim, import or scrot"**:
  Install `maim` or `imagemagick` to enable screen capture.
- **Forced Backend Selection**:
    ```bash
    AntiAFK-RBX-Sober --force-desktop x11
    ```
